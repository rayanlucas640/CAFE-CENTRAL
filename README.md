☕ Café Central Web

📌 Sobre o projeto

O Café Central é uma aplicação web desenvolvida com o objetivo de apresentar uma cafeteria e seus produtos, permitindo aos usuários navegar pelas páginas do sistema e consultar as informações disponíveis no cardápio.

O projeto foi desenvolvido durante a Unidade Curricular e passou por manutenções para melhorar seu funcionamento, organização visual e experiência de utilização.
